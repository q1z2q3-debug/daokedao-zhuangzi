# 润泽说 道可道之庄子

《庄子》**内七篇全帙、外十五篇与杂六篇逐篇深解**的一本读本：字源先行，底本可核，逐段拆解。

全书 **29.8 万字（298,416 字）**，28 篇另附《庄子立言之法度》一卷。每篇同构七层：经文底本、本篇定位、关键字溯源、逐段落深解、故事讲读、本篇总括、附录（诠释分歧与常见误读）。

> 这本书的全部工作，在于**先一个字一个字还原本义，再让庄子自己把「合」与「和」讲出来**。它不做消极避世的转述，也不做权谋养生的比附；主脉一对分辨——合是人为的分类、命名、制度，和是差异各得其位、彼此不害。所破的是把合当成和，所守的是和。

## 二、体例：一篇七层

1. **经文底本** —— 全篇经文，据郭庆藩《庄子集释》校王先谦《庄子集解》，异文随文出注，不强行统一。
2. **本篇定位** —— 该篇在庄子所处的时代与处境中的位置，以及它在全书里的作用。
3. **关键字溯源** —— 逐个回到先秦字形与用例，纠正后世注家读错的地方。
4. **逐段落深解** —— 按经文段落一、二、三……逐段拆解，每段先给结论，再给依据。
5. **故事讲读** —— 庄子以寓言立说，此层只管讲清楚故事本身与它的落点。
6. **本篇总括** —— 一段收束，指明该篇在「合与和」主脉上的位置。
7. **附录：诠释分歧与常见误读** —— 列出历代主要异读，说明本书取舍的理由。
