胠箧

底本：郭庆藩《庄子集释》校王先谦《庄子集解》，异文随文出注　·　全书阅读版　·　篇目

经文底本

将为胠箧、探囊、发匮之盗而为守备，则必摄缄縢、固扃鐍；此世俗之所谓知也。然而巨盗至，则负匮、揭箧、担囊而趋；唯恐缄縢、扃鐍之不固也。然则乡之所谓知者，不乃为大盗积者也？

故尝试论之，世俗之所谓知者，有不为大盗积者乎？所谓圣者，有不为大盗守者乎？何以知其然邪？昔者齐国邻邑相望，鸡狗之音相闻，罔罟之所布，耒耨之所刺，方二千余里。阖四竟之内，所以立宗庙、社稷，治邑、屋、州、闾、乡、曲者，曷尝不法圣人哉！然而田成子一旦杀齐君而盗其国。所盗者岂独其国邪？并与其圣知之法而盗之。故田成子有乎盗贼之名，而身处尧舜之安，小国不敢非，大国不敢诛，专有齐国。则是不乃窃齐国，并与其圣知之法，以守其盗贼之身乎？

尝试论之，世俗之所谓至知者，有不为大盗积者乎？所谓至圣者，有不为大盗守者乎？何以知其然邪？昔者龙逢斩，比干剖，苌弘胣，子胥靡，故四子之贤而身不免乎戮。故盗跖之徒问于跖曰：「盗亦有道乎？」跖曰：「何适而无有道邪！夫妄意室中之藏，圣也；入先，勇也；出后，义也；知可否，知也；分均，仁也。五者不备而能成大盗者，天下未之有也。」由是观之，善人不得圣人之道不立，跖不得圣人之道不行；天下之善人少而不善人多，则圣人之利天下也少而害天下也多。故曰，唇竭则齿寒，鲁酒薄而邯郸围，圣人生而大盗起。掊击圣人，纵舍盗贼，而天下始治矣！

夫川竭而谷虚，丘夷而渊实。圣人已死，则大盗不起，天下平而无故矣。圣人不死，大盗不止。虽重圣人而治天下，则是重利盗跖也。为之斗斛以量之，则并与斗斛而窃之；为之权衡以称之，则并与权衡而窃之；为之符玺以信之，则并与符玺而窃之；为之仁义以矫之，则并与仁义而窃之。

何以知其然邪？彼窃钩者诛，窃国者为诸侯，诸侯之门而仁义存焉。则是非窃仁义圣知邪？故逐于大盗，揭诸侯，窃仁义并斗斛权衡符玺之利者，虽有轩冕之赏弗能劝，斧钺之威弗能禁。此重利盗跖而使不可禁者，是乃圣人之过也。

故曰：「鱼不可脱于渊，国之利器不可以示人。」彼圣人者，天下之利器也，非所以明天下也。故绝圣弃知，大盗乃止；擿玉毁珠，小盗不起；焚符破玺，而民朴鄙；掊斗折衡，而民不争；殚残天下之圣法，而民始可与论议。擢乱六律，铄绝竽瑟，塞瞽旷之耳，而天下始人含其聪矣；灭文章，散五采，胶离朱之目，而天下始人含其明矣；毁绝钩绳而弃规矩，攦工倕之指，而天下始人有其巧矣。故曰：大巧若拙。削曾、史之行，钳杨、墨之口，攘弃仁义，而天下之德始玄同矣。

彼人含其明，则天下不铄矣；人含其聪，则天下不累矣；人含其知，则天下不惑矣；人含其德，则天下不僻矣。彼曾、史、杨、墨、师旷、工倕、离朱，皆外立其德而以爚乱天下者也，法之所无用也。

子独不知至德之世者乎？昔者容成氏、大庭氏、伯皇氏、中央氏、栗陆氏、骊畜氏、轩辕氏、赫胥氏、尊卢氏、祝融氏、伏牺氏、神农氏，当是时也，民结绳而用之，甘其食，美其服，乐其俗，安其居，邻国相望，鸡狗之音相闻，民至老死而不相往来。若此之时，则至治已。今遂至使民延颈举踵，曰「某所有贤者」，赢粮而趣之，则内弃其亲而外去其主之事，足迹接乎诸侯之境，车轨结乎千里之外。则是上好知之过也。

上诚好知而无道，则天下大乱矣。何以知其然邪？夫弓弩毕弋机变之知多，则鸟乱于上矣；钩饵罔罟罾笱之知多，则鱼乱于水矣；削格罗落罝罘之知多，则兽乱于泽矣；知诈渐毒、颉滑坚白、解垢同异之变多，则俗惑于辩矣。故天下每每大乱，罪在于好知。故天下皆知求其所不知而莫知求其所已知者，皆知非其所不善而莫知非其所已善者，是以大乱。故上悖日月之明，下烁山川之精，中堕四时之施；惴耎之虫，肖翘之物，莫不失其性。甚矣，夫好知之乱天下也！自三代以下者是已，舍夫种种之民而悦夫役役之佞，释夫恬淡无为而悦夫啍啍之意，啍啍已乱天下矣！

本篇定位：利器可以被偷走

《胠箧》是外篇第三篇，也是三篇里最锋利的一篇。它往下推了一格，推到很多人不愿推的地方。

骈拇说：外加的标准是多余的。马蹄说：外加的标准会伤人，还会催生机心。胠箧说：外加的标准本身就是一件东西，它可以被拿走。

开篇那个比喻已经把话讲完了：为防盗而捆紧绳索、锁牢门栓，这是世人说的聪明。可大盗来了，整柜扛走，他还怕你捆得不够结实——那些防盗的工夫，等于替大盗打包。

然后庄子把这个比喻推到制度上，推到一个具体的史实上：田成子杀齐君、盗齐国，「并与其圣知之法而盗之」。他偷的不只是国土，还有整套宗庙社稷、乡里法度。所以他背着盗贼的名，过着尧舜的安稳日子，小国不敢非议，大国不敢讨伐。

这一步最刺人：仁义礼法不是天然的护身符，它可以被换一个主人。 谁拿到它，谁就拿到「我是正当的」这句话。而「正当」这句话一旦可以转让，它保护的就不再是善，而是持有它的人。

再往下，庄子把「盗亦有道」摆出来：揣测屋里有什么是圣，抢先破门是勇，断后是义，判断能不能下手是智，分赃均匀是仁。五条齐备才能成大盗。这一段是全篇的刀锋：圣、勇、义、智、仁这五个字，本身没有立场，谁用都一样好用。

于是有了那句被骂了两千年的判词：「圣人不死，大盗不止。」骂它的人多半以为庄子要杀圣人。他其实在说另一件事：只要有一件东西被立为「天下之利器」，就一定会有人来抢它；抢到的人，从此用你的规矩护他的赃。

末段讲「好知」。这是全篇的落点，也是三篇的收束：乱不在盗，在好知。上位者一好知，百姓就延颈举踵去追贤者，抛下亲人、放下本职，足迹遍诸侯之境。庄子一句「则是上好知之过也」，把责任按回到立标准的那一头。

关键字溯源

胠箧。 胠，从肉、去声，本义腋下胁间，引申为从旁撬开；箧，小箱。二字连读，是从侧面撬箱子。这个动作很讲究：不是砸，是撬——找到缝隙，从旁边进去。全篇的方法也是如此。

缄縢、扃鐍。 缄縢是捆扎的绳，扃是门闩，鐍是锁扣。四字合起来，是所有「守备」的总称。庄子用得极准：这些东西防的是小偷，不防大盗——因为大盗连箱子一起搬。

符玺。 符是剖分为二的信物，玺是印信。二者都是「信用」的物质化：把「我说的话可信」这件事，做成一块可以交到别人手里的东西。做成东西的那一刻，它就可以被拿走。

玄同。 玄是幽远不分，同是混同为一。合起来，是消解了分别之后的那种一体——不是把万物捏成一坨，是各含其明、各守其性，而彼此不再以标准相争。老子第六十五章也用「玄同」二字，说的是同一件事。

钩。 衣带上的小金属钩，代指极微末的财物。「窃钩者诛，窃国者为诸侯」——不是比较偷多偷少，是点出量罪的尺子本身站在谁手里。

故事讲读

庄子开篇讲了一件很耐琢磨的事。

有人怕小偷撬箱、掏袋、开柜，于是捆紧绳索，锁牢门栓。这就是世人说的聪明。可大盗一来，扛起柜子、抬走箱子、挑上袋子就跑，他还生怕你捆得不够牢、不好搬。

这么看，刚才那些防盗的聪明，倒像是替大盗提前收拾打包。

顺着往下推：世人说的聪明智谋，有多少不是在替大盗积攒？世人推崇的圣人礼法，又有多少不是在替大盗看守？

当年齐国，城邑相望，鸡犬相闻，国土方圆两千余里。国内建宗庙社稷、划乡里行政，样样都效法圣人之法。可田成子一朝杀齐君、盗齐国。他偷的哪里只是国土？连同圣人定下的整套礼法，一并偷走了。

田成子背着盗贼的名声，却安稳如尧舜，小国不敢非议，大国不敢讨伐，长久占有齐国。这不就是偷了国家，又偷走圣人的法度，用来护住他盗贼的身家？

龙逢被斩，比干被剖，苌弘被刳，子胥沉江——这四人的贤，没能让他们免于一死。

盗跖的手下问他：强盗也有道吗？

盗跖说：哪里会没有！揣测屋里藏着什么，是圣；抢先破门，是勇；断后掩护，是义；判断能不能下手，是智；分赃分得匀，是仁。这五条不齐备而能成大盗的，天下没有。

可见善人不靠圣人这套立不了身，盗跖不靠这套也行不了事。天下好人少、不善的人多，那么这套东西给天下的益处少，祸害多。

嘴唇没了，牙齿就受寒；鲁国的酒淡薄，跟邯郸被围本不相干，可事情就是这么牵连，楚人一句话，邯郸就遭了围——圣人一出现，大盗跟着兴起。打倒圣人，放掉盗贼，天下才开始治。

河水干了，山谷才空；山丘铲平，深渊才满。圣人消亡，大盗不起，天下才安宁。圣人不死，大盗不止。

人们造斗斛来量，大盗连斗斛一起偷走；造秤来称，连秤一起偷走；造符印取信，连符印一起偷走；立仁义来矫正人心，连仁义一并偷走。

所以偷一个衣带钩的处死，偷一个国家的做成诸侯。诸侯的门前，仁义就摆在那里。这不就是把仁义和圣智一并偷走了？

庄子引一句老话：鱼不能离开深水，治国的利器不能拿出来给人看。圣人的这套礼法圣智，就是天下的利器，不宜昭示于人。

于是说：断绝圣智，大盗才止；砸掉珠玉，小偷才不起；烧掉符玺，百姓回归朴素；打碎斗斛折断秤杆，百姓不再相争；废尽天下的圣法，人们才谈得上回本心而论道。

搅乱音律、销毁乐器，堵住师旷的耳朵，天下人才保全自己天然的听觉；抹去五彩、粘住离朱的眼睛，天下人才保全天然的视力；抛弃曲尺墨线，折断工倕的手指，天下人才守住本然的巧。所以说：大巧若拙。削掉曾参、史鰌的行迹，钳住杨朱、墨翟的口舌，攘弃仁义，天下的德才玄同。

人人守住自己内在的明，天下就不被炫惑；守住天然的听，就不被音律拖累；守住本心的知，就不被诡辩迷惑；守住本然之德，就不会走入邪僻。曾史、杨墨、师旷、工倕、离朱，都是把德摆到外面去、反倒搅乱天下的人，这套法度本来无用。

上古至德之世，容成氏、大庭氏、伯皇氏……十二氏相继，百姓结绳记事，吃得香甜，穿得合宜，安于居所，乐在风俗；邻国相望，鸡犬相闻，人到老死不相往来。那时候，就是至治。

如今百姓伸着脖子踮着脚，听说某处有贤人，就背着粮食跑去追随，抛下亲人、放下本职，足迹接于诸侯之境，车辙结于千里之外。这是上位者好知带来的过错。

上位者好知而不守道，天下就大乱。弓弩罗网的机巧多了，鸟乱于上；钓饵网罟多了，鱼乱于水；捕兽的陷阱多了，兽乱于泽；诡辩、坚白同异的言辞多了，世俗惑于辩说。

天下屡屡大乱，罪在好知。世人都拼命去求自己不知道的，却不去求自己已经知道的；都去批评别人不好的，却不去反省自己所推崇的善也有弊病。这样一来，上悖日月之明，下烁山川之精，中堕四时之施，连微小的虫豸都失了本性。

好知乱天下，厉害到这个地步。三代以来都是如此：舍下淳朴的百姓，偏爱机巧善辩的佞人；放下恬淡无为，偏爱喋喋不休的说教。正是这些喋喋不休，搅乱了天下。

深度解读：时代背景与全书联动

时代背景。 战国中期之后，礼义、法度、符玺、度量衡次第建立。一面用来规范秩序，一面也成了可被接管的现成机器：诸侯权臣不必另造一套，只要把现成的拿过来，就能借仁义之名巩固统治。田氏代齐是最典型的例子——篡了国，仍用齐国整套礼法，借圣人之名自固。庄子后学目睹名教被窃用，写下这一篇，戳破「礼法天然正义」的幻象。

联动《应帝王》「鱼不可脱于渊」。 本篇直接引此句。《应帝王》里它是讲「无容私」——权柄不能脱离大道；到《胠箧》，它被用在另一面：脱离了大道的利器，就成了人人都能捡起来用的东西。

联动《马蹄》素朴。 马蹄讲驯化，胠箧讲窃取，是同一件事的两个阶段。先有一套标准把人性压成统一的形状，然后这套标准被更强的人接手——先塑形，再易主。

联动《齐物论》。 齐物说没有一把尺是物的本尺。胠箧加了一句更冷的注解：既然尺不是物的，那它就是人的；是人做的，就可以换手。是非标准一旦建立，就可以被颠倒借用——大盗借仁义，就是这套标准崩坏的实证。

联动《道德经》第三十六章。 「鱼不可脱于渊，国之利器不可以示人」出自老子。老子说的是权柄的藏，庄子把它推到「利器本身可以被夺」——藏得住一时，藏不住一世；只要它是一件东西，就迟早换主人。

合与和：能被偷走的秩序，与偷不走的东西

人为之合：建立统一的礼法、仁义、度量、赏罚，把天下规整成一个模样，用制度锁死秩序。可这套「合」是外在框架——框架能被盗取，大盗拿着你的框架，包装他的掠夺。合到这个程度，秩序还在，只是换了主人。

道境之和：不向外树立一套可被窃取、可被利用的圣智符号。万物各含其明、各守其性，没有固定的评判标尺，没有一块可以劫持的「仁义招牌」，回归浑然玄同，自然不相侵害。

分界就在这一句上：凡是拿得走的东西，都不是和。 能被偷走的秩序只是合；偷不走的，是各人心里那一点自己听见、自己看见的明。

常见误读

一、以为庄子主张砸毁一切文明、退回原始野蛮。 不是。「绝圣弃知」那一串排比，读作字面就全错——庄子要毁的不是器物，是那件「利器」的资格：把一套价值立成天下的凭据，谁拿到谁正当。器物毁不毁，与这件事无关。真去砸符烧玺，正是他说的「以人助天」。

二、以为「圣人不死，大盗不止」是在骂圣人该死。 这句话说的是结构，不是人身。只要「圣人」被立成一个位置，这个位置就会招人来坐；坐上的人不必是圣人，可以是田成子。庄子要拆的是那个位置，不是那个人。

三、以为「盗亦有道」是在夸盗跖聪明。 相反，这是全篇最冷的一段：它证明圣、勇、义、智、仁这五个字没有立场，盗贼用起来一样顺手。这五个字一旦从人心里抽出来、变成一套可传授的技术，就不再属于善。
