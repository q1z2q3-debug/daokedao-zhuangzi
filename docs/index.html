这本书主张什么

古今解庄者多落三途：读作消极避世，读作权谋养生，或止于逐字考据。本书立一对分辨为读庄主脉——合与和：合是人为的分类、命名、制度，和是差异各得其位、彼此不害。庄子所破的是把合当成和，所守的是和。

三言法度、天倪天均、物化生死诸题，皆以此辨贯穿；关键字回到先秦字形与用例，底本以《庄子集释》为主，异文两存，不强行统一。
